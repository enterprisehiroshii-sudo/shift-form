# シフト申請フォーム（公開用）

スタッフがスマホで開くための、シフト申請フォームです。
`index.html` の1枚だけで動きます。サーバーもアカウントも使いません。

GitHub Pages で公開し、そのURLをQRコードにして事務所に掲示します。

## 個人情報を含みません

スタッフ名簿はこのファイルに入っていません。氏名は自由入力です。
名簿は店長が集計画面で登録し、店長の端末（ブラウザの localStorage）にだけ保存されます。

そのためこのリポジトリは公開して差し支えありません。

## 開発について

このフォームの元となる作業一式（掲示物、対象月の切り替え手順、設計の記録）は
別のプライベートリポジトリで管理しています。`index.html` はそこからの複製です。
